# Правила общения

Yamuse — независимый проект для Windows. Эти правила действуют в Issues, pull request, комментариях и других пространствах проекта.

## Уважительное участие

- Обсуждайте код, поведение программы и решения по существу. Критикуйте предложение, а не человека.
- Учитывайте разный опыт участников. Задавайте уточняющие вопросы и объясняйте замечания.
- Уважайте личные границы, решения модерации и право человека прекратить разговор.
- Не публикуйте чужие личные данные, переписку, токены и другие секреты.

Недопустимы оскорбления, дискриминация, угрозы, травля, сексуальные домогательства, преследование и спам. Повторное давление на участника после просьбы остановиться также нарушает эти правила.

## Модерация

За модерацию пространств репозитория отвечает его владелец. В зависимости от ситуации он может попросить изменить сообщение, скрыть или удалить содержимое, закрыть обсуждение либо ограничить участие. Решение должно учитывать само нарушение и его влияние на других людей; несогласие с техническим решением само по себе не является нарушением.

## Как сообщить о нарушении

Для нарушений правил GitHub используйте встроенное действие **Report content** или [инструкцию GitHub по сообщениям о злоупотреблениях](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Обращение в GitHub Support рассматривает GitHub; это не личный канал связи с владельцем Yamuse. Доступность отправки отчёта администраторам репозитория зависит от настроек GitHub.

Не размещайте чувствительные подробности в публичном обсуждении. Сохраните ссылки и необходимый контекст для доступного приватного канала отчёта. Отдельный приватный контакт владельца проекта здесь не объявлен.

Для технических уязвимостей используйте порядок из [SECURITY.md](SECURITY.md).
