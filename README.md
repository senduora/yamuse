# YMusic Native

Неофициальный прототип клиента Яндекс Музыки для Windows 10/11 x64. Интерфейс WPF и системный аудиоплеер; WebView, Chromium и Electron в клиент не включены.

[Скачать установщик](https://github.com/senduora/ymusic-native/releases/latest/download/YMusic.Native-win-Setup.exe) · [Все выпуски](https://github.com/senduora/ymusic-native/releases)

## Что есть в 0.3.7

- Вход через страницу Яндекса, избранное, коллекция и поиск по трекам, артистам, альбомам, подборкам и плейлистам.
- Карточки исполнителей с популярными треками и месячной аудиторией, когда её возвращает сервис. Артистов можно открыть из списка и нижнего плеера; альбом — по названию в колонке.
- Моя волна и волна по коллекции, очередь, предзагрузка и переходы между треками.
- Скачивание выбранных треков и плейлистов, до10 одновременных загрузок, опциональное автоскачивание избранного. Файлы сохраняются в «Документы\YMusic Native\Music».
- Обложки, встроенный текст, синхронизация при наличии таймкодов. Дополнительные источники: LRCLIB с точным сопоставлением и Genius для отсутствующего текста.
- Переработанные кнопки, текстовые ссылки и плавная прокрутка с учётом физических пикселей экрана.

## Установка и обновления

Setup включает .NET 8.0.32 и устанавливается для текущего пользователя. Авторизация GitHub для загрузки установщика и обновлений не нужна. Данные входа и настройки находятся отдельно в `%LOCALAPPDATA%\YMusic.Native.Prototype`; скачанная музыка — в «Документах».

Установленная версия проверяет обновления при запуске. В настройках доступны проверка, скачивание и отдельное «Обновить и перезапустить»; скачивание не прерывает музыку. Переносимая версия не обновляется автоматически.

Установщик пока без подписи Authenticode. В этой версии проверены упаковка и содержимое, но установка, удаление и полный цикл обновления в отдельном пользовательском профиле ещё не проверены.

## Ограничения

Это прототип, полного совпадения с официальным клиентом нет. Выбранное качество не гарантирует определённый кодек: показывается фактический ответ сервера. Причина получения192кбит/с в исследуемом случае пока не устранена; соответствие максимальному качеству официального клиента не подтверждено.

Доступность музыки, рекомендаций, качества и текстов зависит от ответа сервиса. Синхронные таймкоды не выдумываются. Восстановление очереди после перезапуска и другие запланированные возможности ещё отсутствуют.

## Сборка и проверки

Для разработки нужны Windows и .NET8 SDK. Вход, пользовательская музыка и сторонние приложения для стандартных проверок не требуются.

```powershell
dotnet build src/YMusic.Native/YMusic.Native.csproj -c Release
dotnet run --project tests/YMusic.Native.Checks/YMusic.Native.Checks.csproj -c Release -- work/check-results
```

Общая проверка0.3.7:69/69PASS на итоговом productDLL. Основные тесты используют synthetic HTTP, собственные временные папки и muted WAV. Дополнительно проверены25сценариев update-service и содержимое установщика. Это самопроверка, не независимое review и не проверка полного паритета.

Упаковка закрепляет Velopack/vpk1.2.161 и runtime8.0.32. Подробности: [tools/packaging/README.md](tools/packaging/README.md). Сборка и размещение релиза — отдельные шаги; packscript ничего не публикует.

```powershell
./tools/packaging/Pack-Installer.ps1 -Version 0.3.7 -OutputFolder ./artifacts/setup -WorkFolder ./work/package
```
