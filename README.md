## Установка

Нужна **Windows 10 или 11 x64**. .NET Runtime уже включён в обе сборки.

1. Скачайте [установщик](https://github.com/senduora/yamuse/releases/latest/download/Yamuse-win-Setup.exe) и запустите его.
2. Откройте Yamuse, нажмите **«Войти»** и завершите вход на странице Яндекса.

Установка выполняется для текущего пользователя. Для запуска из папки скачайте [Portable-архив](https://github.com/senduora/yamuse/releases/latest/download/Yamuse-win-Portable.zip), распакуйте его и откройте `YMusic.Native.exe`.

## Возможности

| | Что доступно |
| --- | --- |
| **Коллекция и поиск** | «Мне нравится», плейлисты, альбомы, исполнители и история. Поиск по трекам, музыкантам, альбомам, подборкам и плейлистам; сортировка списков. |
| **Рекомендации** | Моя волна, волна по коллекции и по выбранному треку. Карточки исполнителей с популярными треками, дискографией и похожими музыкантами. |
| **Воспроизведение** | Предзагрузка следующего трека, кроссфейд 0–10 секунд, выбор качества, скорости и выравнивание громкости. Выбор устройства вывода для онлайна, офлайна и кроссфейда. |
| **Очередь и таймер** | Перетаскивание нескольких треков, групповые действия и отмена удаления через **Ctrl+Z**. Таймер сна на 15, 30, 60 минут или до конца трека с плавным затиханием. |
| **Офлайн** | Скачивание треков и плейлистов, автоскачивание избранного, до 10 параллельных загрузок. Прогресс, пауза, продолжение и повтор ошибок в Центре загрузок. |
| **Тексты песен** | Текст внутри приложения, подсветка строк при наличии таймкодов и переход к строке по нажатию. Ручная прокрутка временно приостанавливает автоматическое следование. |
| **Режимы проигрывателя** | Полноэкранный режим с обложкой, очередью слева и текстом справа. Мини-плеер с изменяемым размером, скрываемой обложкой и закреплением поверх окон. |
| **Оформление** | Белая, тёмная и системная темы; по умолчанию — как в Windows. Золотистый акцент, свой цвет или акцент по обложке с плавной сменой за 5 секунд. |
| **Интеграция с Windows** | Трей, системные медиакнопки, горячие клавиши и навигация боковыми кнопками мыши. Очередь и позиция сохраняются между запусками; продолжение — только по Play. |

Yamuse написан на **C# / .NET 10 / WPF**. Воспроизведение и анализ громкости используют системные медиакомпоненты Windows; выравнивание громкости не изменяет аудиофайлы.

## Управление

| Клавиша | Действие |
| --- | --- |
| **Пробел** или **P** | Воспроизведение / пауза |
| **[** / **]** | Предыдущий / следующий трек |
| **M** | Выключить звук / вернуть громкость |
| **+** / **−** | Изменить громкость на 10 пунктов |
| **L** | Поставить или снять лайк |
| **F11** | Открыть / закрыть полноэкранный проигрыватель |
| **Esc** | Вернуться из проигрывателя, настроек или текста песни |
| **Ctrl+Z** | Отменить последнее удаление в открытой очереди |

Горячие клавиши не мешают вводу в текстовых полях. Название трека или обложка открывают альбом, имя исполнителя — его карточку. Действия с треком доступны через **«⋯»** в списке и плеере.

<details>
<summary><strong>Очередь и полноэкранный режим</strong></summary>

- Перетаскивание треков доступно в исходном порядке очереди без фильтра. **Ctrl+Z** возвращает удалённые треки, не запуская воспроизведение.
- Сортировка очереди меняет только её отображение. При новом запуске из коллекции очередь создаётся в видимом порядке; **«Исходный порядок»** возвращает порядок сервиса.
- В полноэкранном режиме можно показать очередь, текст песни или обе панели. Переход к очереди или источнику воспроизведения помогает найти текущий трек.
- Экран остаётся включённым, пока полноэкранный проигрыватель виден и музыка играет. На паузе действует обычное поведение Windows.

</details>

<details>
<summary><strong>Скачивание и недоступные треки</strong></summary>

- Нажмите **«Скачать»** у трека или плейлиста. Автоскачивание «Мне нравится» и число одновременных загрузок **1–10** выбираются в настройках.
- В **«Центре загрузок»** доступны пауза, продолжение и повтор ошибок; готовая музыка находится в **«Скачанном»**. После перезапуска незавершённая очередь восстанавливается на паузе. Готовые файлы используются повторно, незавершённый трек скачивается заново.
- Чтобы убрать недоступные треки из избранного, выделите их через **Ctrl/Shift** или кнопку **«Недоступные»** и нажмите **«Убрать лайки»**. После подтверждения сервиса они исключаются из повторных попыток загрузки избранного; скачанные файлы сохраняются.

</details>

## Настройки и обновления

Все настройки применяются и сохраняются сразу. В разделе **«Внешний вид»** можно сменить тему и выбрать акцент из палитры, по HEX-коду или по обложке. Сворачивание в трей настраивается для закрытия крестиком; обычное сворачивание оставляет окно на панели задач.

В нижней строке — версия, RAM, CPU, ссылки **GitHub** и **Changelog**, проверка обновлений и индикатор нового выпуска. Частота проверки выбирается в настройках: при запуске, каждый час, день, неделю, месяц или вручную при отключённой автопроверке.

Установленная версия скачивает обновление во время работы плеера и применяет его по кнопке **«Обновить и перезапустить»**. Portable открывает страницу выпуска для ручного скачивания. Приложение и обновления доступны в публичных релизах GitHub без авторизации.

## Музыка и данные

| Что хранится | Где |
| --- | --- |
| Музыка и офлайн-индексы | `Документы\Yamuse\Music` |
| Сохранённый вход и настройки | `%LOCALAPPDATA%\Yamuse` |
| Установленное приложение | `%LOCALAPPDATA%\YMusic.Native` |

«Документы» — системная папка Windows, в том числе если она перенесена. Сохранённый вход защищён Windows DPAPI для текущего пользователя. Очистка кэша и скачанной музыки доступна в настройках.

В установленной версии для полного удаления откройте **Настройки → Удаление приложения → «Удалить Yamuse полностью…»**. После явного подтверждения удаляются приложение, ярлыки, вход, настройки, кэш, диагностика, скачанные Yamuse треки и локальные плейлисты. Посторонние и изменённые аудиофайлы сохраняются; приложение покажет их папку. Удалённые данные восстановить нельзя.

## Разработка

Нужны **Windows x64** и **.NET SDK 10.0.403**, закреплённый в [global.json](global.json).

```powershell
git clone https://github.com/senduora/yamuse.git
cd yamuse
dotnet run --project src/YMusic.Native/YMusic.Native.csproj -c Release
```
