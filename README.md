## Возможности

| | Что умеет клиент |
| --- | --- |
| **Ваша коллекция** | Вход через Яндекс, «Мне нравится», плейлисты, альбомы, исполнители и история прослушивания. |
| **Сортировка** | Нажимаемые заголовки колонок и выбор порядка у названия раздела. Название, исполнитель, альбом, длительность и наличие скачанного файла; для загрузок — также состояние, прогресс и размер. Направление и критерий сохраняются отдельно для разделов. |
| **Музыка под настроение** | Моя волна и отдельная волна по коллекции. |
| **Поиск** | Треки, исполнители, альбомы, сборники, редакционные подборки и плейлисты — с отдельными категориями выдачи. |
| **Исполнители и альбомы** | Карточки музыкантов, популярные треки, месячная аудитория из данных сервиса, дискография и похожие исполнители. Артисты открываются из списков и плеера, альбомы — из колонки в списке треков. |
| **Воспроизведение** | Быстрый старт поддерживаемых онлайн-потоков до полной загрузки, предзагрузка следующего трека и кроссфейд от 0 до 10 секунд. Очередь, текущий трек, позиция, перемешивание и повтор сохраняются для вашего аккаунта; продолжение — по нажатию Play. |
| **Настройки звука** | Качество «Превосходное», «Оптимальное», «Экономичное», скорость и выравнивание громкости. Коррекция ослабляет громкие треки, сохраняет исходные файлы и сочетается с кроссфейдом. |
| **Действия с треками** | Воспроизведение с обложки, лайки и зелёные отметки скачивания во всех списках. Общее меню списка и плеера: играть следующим, добавить в очередь или плейлист, скачать, убрать из офлайна, открыть альбом или исполнителя, скопировать ссылку. |
| **Офлайн** | Скачивание отдельных треков и целых плейлистов, до 10 одновременных загрузок и автоскачивание избранного. Компактный круговой прогресс учитывает только недостающие треки. Занимаемое место, пауза, продолжение и повтор неудачных загрузок. |
| **Обложки и тексты** | Обложки в коллекции и плеере, встроенный текст песни и подсветка строк при наличии таймкодов. Плавная ручная прокрутка текста и переход к нужной строке. |
| **Полноэкранный проигрыватель** | Крупная обложка, очередь слева и текст справа — панели можно показывать отдельно или вместе. Перемешивание, повтор, переход к источнику музыки и текущему треку. Экран остаётся включённым во время воспроизведения. |
| **Мини-плеер** | Окно с изменяемым размером, адаптивной компоновкой, таймлайном, лайком, громкостью и переключением треков. Обложку можно скрыть, освободив место для управления, а окно — закрепить поверх остальных. |
| **Оформление и настройки** | Белая, тёмная и системная темы; по умолчанию — как в Windows. Золотистый акцент или цвет обложки с плавной сменой за 5 секунд, мягкий фон волны и проигрывателя. Настройки находятся в центре основного окна, изменения применяются и сохраняются сразу. |
| **Удобство Windows** | Значок в трее, системные медиакнопки, заголовки окон в выбранной теме, горячие клавиши, боковые кнопки мыши для переходов назад и вперёд, плавная прокрутка. |
| **Полное удаление** | Удаление приложения, сохранённого входа, настроек, кэша и скачанной музыки с явным подтверждением. |

Интерфейс работает на WPF, воспроизведение — через системные медиакомпоненты Windows, анализ громкости — через Media Foundation. В основе клиента — C# и .NET 8.

## Внешний вид

В **Настройках → Внешний вид** выберите белую, тёмную или системную тему. По умолчанию Yamuse следует оформлению Windows. Все изменения настроек применяются и сохраняются сразу.

Золотистый акцент можно заменить цветом из палитры или HEX-кодом либо включить **«Акцент по обложке»**. Цвет определяется по наибольшей области обложки и адаптируется для читаемости в выбранной теме. Переход к новому цвету занимает 5 секунд.

Команда **«Волна по этому треку»** в контекстном меню списка и проигрывателя запускает рекомендации Яндекса на основе выбранной композиции. В карточках и шапках плейлистов показывается имя автора, если сервис его предоставляет или это ваш собственный плейлист.

Большие коллекции отображаются с фоновой проверкой скачанных треков. В настройках доступны отдельные действия для очистки кэша и удаления скачанной музыки с отображением хода операции.

## Управление

| Клавиша | Действие |
| --- | --- |
| **F11** | Открыть или закрыть полноэкранный проигрыватель. |
| **Esc** | Вернуться из проигрывателя, настроек или текста песни. |
| **Пробел** или **P** | Воспроизведение / пауза. |
| **[** / **]** | Предыдущий / следующий трек. |
| **M** | Выключить звук или вернуть прежнюю громкость. |
| **+** / **−** | Изменить громкость на 10 пунктов. |
| **L** | Добавить текущий трек в «Мне нравится» или убрать его оттуда. |

Горячие клавиши не мешают вводу в текстовых полях. Боковые кнопки мыши переключают историю разделов назад и вперёд.

## Установка

1. Скачайте [Yamuse-win-Setup.exe](https://github.com/senduora/yamuse/releases/latest/download/Yamuse-win-Setup.exe).
2. Запустите установщик и откройте Yamuse.
3. Нажмите «Войти» и завершите вход на странице Яндекса.

Установщик включает .NET Runtime и устанавливает приложение для текущего пользователя. Для доступа к музыке используется ваш аккаунт Яндекса.

Для запуска из папки скачайте [Portable-архив](https://github.com/senduora/yamuse/releases/latest/download/Yamuse-win-Portable.zip), распакуйте его и откройте `YMusic.Native.exe`.

## Обновления

В нижней строке доступны версия с текущим акцентом, RAM и CPU, ссылки **GitHub** и **Changelog**, ручная проверка и индикатор нового выпуска. В настройках выберите частоту проверки: при запуске, каждый час, день, неделю, месяц или отключите её.

В установленной версии можно скачать обновление и нажать **«Обновить и перезапустить»** в удобный момент. Скачивание идёт во время работы плеера. Portable также проверяет новые версии и открывает официальный выпуск для скачивания.

Для загрузки приложения и обновлений используется анонимный доступ к публичным релизам GitHub.

## Скачанная музыка и данные

Выберите трек или плейлист и нажмите **«Скачать»**. Для избранного доступна настройка **«Автоматически скачивать “Мне нравится”»**. Число одновременных загрузок выбирается в настройках — от 1 до 10.

В разделе **«Загрузки»** можно приостановить текущую очередь, продолжить её и повторить треки с ошибками. Готовые файлы используются повторно; незавершённый трек при продолжении скачивается заново.

Чтобы убрать недоступные треки из коллекции, выделите их в **«Загрузках»** с помощью **Ctrl/Shift** или кнопки **«Недоступные»**, затем нажмите **«Убрать лайки»**. То же действие доступно по правой кнопке мыши. После подтверждения сервиса треки исчезнут из избранного и получат отметки в истории загрузок. В очереди «Мне нравится» они также исключаются из повторных попыток; скачанные файлы сохраняются.

Нажатие на название трека или обложку открывает его альбом. В шапке альбома или плейлиста показаны обложка, название, доступные даты, число треков и длительность. Боковые кнопки мыши переключают историю разделов назад и вперёд, сохраняя фильтр и положение списка.

Кнопка **«Развернуть проигрыватель»** или **F11** плавно открывает полноэкранный режим. Кнопки очереди и **«Тт»** показывают очередь слева и текст справа: можно оставить одну обложку, добавить одну панель или обе. Здесь же доступны перемешивание, повтор и переход к источнику музыки. Открытие очереди или источника помогает найти текущий трек, в том числе среди повторяющихся композиций.

Текст плавно следует за текущей строкой; ручная прокрутка временно приостанавливает слежение. Нажмите строку с таймкодом, чтобы перейти к ней. **Esc** или **F11** возвращает обычный интерфейс. Пока полноэкранный проигрыватель виден и музыка играет, экран остаётся включённым; пауза возвращает обычное поведение Windows. Сохранение замеров ресурсов доступно в настройках.

При первом запуске обновление переносит прежние настройки, сохранённый вход и музыку в папки Yamuse без повторного скачивания. Настройка трея относится к закрытию крестиком; обычное сворачивание сохраняет окно на панели задач.

В **Настройках → Воспроизведение** доступно **«Выравнивать громкость треков»**. Настройка сохраняется между запусками. Измерения кэшируются локально, а исходные аудиофайлы не переписываются.

Для сортировки нажмите заголовок колонки или выберите поле справа от названия раздела. Стрелка рядом меняет направление. Пункт **«Исходный порядок»** возвращает порядок сервиса; в поиске сохраняются группы результатов. Сортировка очереди меняет её отображение, а порядок воспроизведения управляется отдельными кнопками. При новом запуске из коллекции очередь создаётся в видимом порядке.

| Данные | Папка |
| --- | --- |
| Музыка и офлайн-индексы | `Документы\Yamuse\Music` |
| Авторизация и настройки | `%LOCALAPPDATA%\Yamuse` |
| Установленное приложение | `%LOCALAPPDATA%\YMusic.Native` |

Вход сохраняется локально с защитой Windows DPAPI для текущего пользователя. Офлайн-файлы и настройки хранятся отдельно от файлов приложения.

В установленном приложении откройте **Настройки → Удаление приложения → «Удалить Yamuse полностью…»**. После подтверждения удалятся приложение, ярлыки, сохранённый вход, настройки, кэш, диагностика, скачанные Yamuse треки и локальные плейлисты. Посторонние и изменённые аудиофайлы сохраняются; приложение покажет папку с ними. Удалённые данные восстановить нельзя.

После запуска установленного Yamuse эта же процедура доступна через удаление приложения в параметрах Windows. Если файл занят или очистка прервалась, можно повторить удаление; приложение сообщит, какие данные остались.

## Разработка

Нужны **Windows** и **.NET 8 SDK**.

```powershell
git clone https://github.com/senduora/yamuse.git
cd yamuse
dotnet run --project src/YMusic.Native/YMusic.Native.csproj -c Release
```

Проверки используют временные папки, тестовые HTTP-ответы и аудиофайлы:

```powershell
dotnet run --project tests/YMusic.Native.Checks/YMusic.Native.Checks.csproj -c Release -- work/check-results
```

Упаковка установщика и файлов обновления:

```powershell
./tools/packaging/Pack-Installer.ps1 -Version 0.4.1 -OutputFolder ./artifacts/setup -WorkFolder ./work/package
```

Подробности сборки и упаковки — в [руководстве](tools/packaging/README.md), правила нумерации — в [docs/VERSIONING.md](docs/VERSIONING.md).
