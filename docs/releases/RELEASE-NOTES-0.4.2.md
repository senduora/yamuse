# Yamuse 0.4.2

Изменения относительно опубликованной [версии 0.4.1](https://github.com/senduora/yamuse/releases/tag/v0.4.1).

- На главной появилась графика «Моей волны» и волны по коллекции. Исправлен запрос подборок и расширена загрузка доступных музыкальных разделов сервиса.
- Значок волны стал единым в навигации, карточках и действиях с музыкой. Волна по коллекции дополнена сердечком, в том числе в «Мне нравится».
- Технический раздел «Загрузки» переименован в «Центр загрузок», получил отдельный значок и пояснение. Из него можно перейти к готовой музыке в «Скачанное».
- В светлой теме динамический фон сохраняет оттенки обложки и читаемость текста. Плавная смена цвета и поведение тёмной темы сохранены.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
