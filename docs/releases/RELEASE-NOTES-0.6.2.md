# Yamuse 0.6.2

Исправления относительно опубликованной [версии 0.6.1](https://github.com/senduora/yamuse/releases/tag/v0.6.1):

- Исправлена потеря очереди загрузок при сбое или отмене обновления. Незавершённые загрузки сохраняются для продолжения.
- Исправлено автоскачивание избранного после удаления отдельного скачанного трека: загрузка возобновляется после обновления списка. Ручная пауза и отмена сохраняются.
- Воспроизведение больше не возобновляется при недоступном выбранном аудиоустройстве.
- Исправлена работа паузы во время переключения аудиоустройства и перехода к предзагруженному треку. Состояние трека корректно сохраняется при паузе и срабатывании таймера сна.
- Статус исполнителя «В коллекции» правильно обновляется при переходах назад и вперёд после добавления или удаления.
- Исправлена надпись «Очередь пуста», которая могла появляться при оставшихся треках. После отмены удаления отображается правильное состояние.
- Поиск без совпадений теперь предлагает изменить запрос вместо повторного предложения ввести его.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**. Оба пакета включают .NET 10 runtime.
