# Yamuse 0.5.0

Изменения относительно опубликованной [версии 0.4.2](https://github.com/senduora/yamuse/releases/tag/v0.4.2).

- Очередь поддерживает перетаскивание нескольких треков, групповые действия и возврат последнего удаления кнопкой или Ctrl+Z. Отмена сохраняет текущее воспроизведение.
- Таймер сна ставит музыку на паузу через 15, 30 или 60 минут либо после текущего трека. Перед остановкой звук плавно затихает, обычная громкость и позиция сохраняются.
- В настройках можно выбрать системный вывод, наушники или колонки. Выбор действует для онлайн-музыки, скачанных треков и кроссфейда; отключение выбранного устройства ставит музыку на паузу.
- После закрытия приложения незавершённая очередь скачивания восстанавливается на паузе. Продолжение и повтор ошибок доступны в «Центре загрузок», готовые файлы не скачиваются заново.
- Приложение перешло на .NET 10 LTS. Установщик и Portable включают runtime 10.0.14; отдельно устанавливать .NET для запуска Yamuse не требуется.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.

Если у вас уже установлена предыдущая сборка 0.5.0, скачайте обновлённый пакет вручную: номер версии сохранён, поэтому автоматическая проверка повторно его не предложит.
