# Yamuse 0.3.10

- Обложки персональных подборок «Премьера», «Дежавю» и «Плейлист дня» на главной странице.
- Полное удаление Yamuse из настроек приложения с подтверждением очистки сохранённого входа, настроек, кэша и скачанной музыки.
- Та же процедура удаления через параметры Windows после запуска установленного приложения.
- Сохранение посторонних и изменённых аудиофайлов с указанием их папки.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.

В установленной версии обновление доступно в **Настройках**: «Проверить обновления» → «Скачать обновление» → «Обновить и перезапустить».
