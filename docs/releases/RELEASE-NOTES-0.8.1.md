# Yamuse 0.8.1

Исправлено сохранение треков FLAC в контейнере MP4 для офлайн-прослушивания. В 0.8.0 такая загрузка могла завершиться ошибкой после получения всего файла. После обновления откройте «Центр загрузок» и нажмите «Повторить» для неудачных загрузок.

Предыдущий стабильный выпуск — [Yamuse 0.8.0](https://github.com/senduora/yamuse/releases/tag/v0.8.0).

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки скачайте **Yamuse-win-Portable.zip**.

[Изменения в исходниках](https://github.com/senduora/yamuse/compare/v0.8.0...v0.8.1)
