# Yamuse 0.3.15

- Акцент по преобладающему цвету обложки с плавным переходом за 5 секунд. Автоматический выбор можно отключить, выбрать статичный цвет из палитры или задать HEX-код.
- Мягкий анимированный фон «Моей волны», волны по коллекции и развёрнутого проигрывателя.
- «Волна по этому треку» в контекстном меню списков и проигрывателя — рекомендации Яндекса на основе выбранной композиции.
- Обновлённая кнопка повтора, ровные отступы кнопок и аккуратные состояния фокуса.
- Подсветка и нажатие названий, альбомов и исполнителей ограничены областью текста. Наведение плавно снимается при уходе курсора.
- Отображение автора плейлиста в карточках и шапке.
- Быстрое открытие больших коллекций с фоновой проверкой офлайн-треков.
- Общий прогресс скачивания в плейлисте и разделе «Загрузки», отдельные счётчики сохранённых, недоступных и ошибочных треков.
- Ускоренная очистка скачанной музыки с прогрессом и отдельная кнопка очистки кэша в настройках.
- История версий перенесена в `docs/releases/`.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
