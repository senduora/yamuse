# Yamuse 0.9.2

Исправлено обновление списка «Мне нравится». Если часть ответа Яндекса содержит противоречивые сведения, Yamuse уточняет данные для затронутых треков и продолжает обновлять список. Треки, сведения о которых пока не удалось подтвердить, остаются в избранном.

Предыдущий стабильный выпуск — [Yamuse 0.9.1](https://github.com/senduora/yamuse/releases/tag/v0.9.1).

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки скачайте **Yamuse-win-Portable.zip**.

[Изменения в исходниках](https://github.com/senduora/yamuse/compare/v0.9.1...v0.9.2)
