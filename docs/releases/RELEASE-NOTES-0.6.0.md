# Yamuse 0.6.0

Изменения относительно опубликованной [версии 0.5.3](https://github.com/senduora/yamuse/releases/tag/v0.5.3).

- Музыка продолжается после последнего трека, если повтор выключен: после альбома включается волна по этому альбому, после плейлиста или отдельной песни — волна по последнему сыгранному треку. Таймер сна по-прежнему останавливает воспроизведение.
- В открытом альбоме появилась кнопка «Волна по альбому» для запуска рекомендаций Яндекса.
- Исправлено автоскачивание избранного: новый трек ставится на загрузку сразу после подтверждённого лайка, без ожидания обновления всего списка, в том числе после восстановления завершённой очереди при запуске приложения.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**. Оба пакета включают .NET 10 runtime.
