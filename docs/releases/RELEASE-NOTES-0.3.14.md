# Yamuse 0.3.14

Изменения относительно опубликованной [версии 0.3.9](https://github.com/senduora/yamuse/releases/tag/v0.3.9).

- Быстрый запуск онлайн-треков до полной загрузки с поддержкой перемотки.
- Сохранение очереди, позиции, перемешивания и повтора для аккаунта. Продолжение прослушивания по нажатию Play.
- Новый раздел «Загрузки»: прогресс каждого трека, пауза, продолжение, повтор загрузки и занимаемое место.
- Сортировка треков, коллекций, поиска и загрузок. Поле и направление запоминаются для каждого раздела; можно вернуть исходный порядок.
- Выравнивание громкости в настройках с локальным кэшем измерений без изменения исходных аудиофайлов.
- Обложки персональных подборок «Премьера», «Дежавю» и «Плейлист дня» на главной странице.
- Новый оранжевый акцент и единое оформление кнопок, меню и текстовых ссылок.
- Переработанный проигрыватель с увеличенной обложкой и полноэкранным режимом. Тексты открываются справа с плавным перемещением обложки.
- Открытие альбома по названию трека и обложке, запятые между исполнителями и подсветка ссылок акцентным цветом.
- Шапки альбомов и плейлистов с обложкой, датой, числом треков и длительностью.
- Навигация назад и вперёд боковыми кнопками мыши с сохранением состояния списка.
- Выделение нескольких треков в «Загрузках» через Ctrl/Shift, быстрое выделение недоступных композиций и компактные кнопки со счётчиком выделения.
- Снятие лайка с одного или всех выбранных треков, включая недоступные, с прогрессом и подтверждением сервисом. Убранные композиции исключаются из повторного скачивания избранного.
- Нижняя строка показывает версию, RAM и CPU; сохранение замеров перенесено в настройки. Пометка «Офлайн» находится рядом с качеством звука в проигрывателе.
- Настройка трея применяется при закрытии крестиком. Обычное сворачивание оставляет приложение на панели задач.
- Папки музыки, настроек и кэша называются Yamuse. Прежние данные переносятся без повторного скачивания.
- Полное удаление приложения и его данных из настроек Yamuse и через параметры Windows. Перед очисткой запрашивается подтверждение; посторонние и изменённые аудиофайлы сохраняются.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
