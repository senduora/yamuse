# Yamuse 0.3.14

- Новый оранжевый акцент и единое оформление кнопок, меню и текстовых ссылок.
- Переработанный проигрыватель с увеличенной обложкой и полноэкранным режимом. Тексты открываются справа с плавным перемещением обложки.
- Открытие альбома по названию трека и обложке, запятые между исполнителями и подсветка ссылок акцентным цветом.
- Информативные шапки альбомов и плейлистов с обложкой, датой, числом треков и длительностью.
- Навигация назад и вперёд боковыми кнопками мыши с сохранением состояния списка.
- Выделение нескольких треков в «Загрузках» через Ctrl/Shift и быстрое выделение недоступных композиций.
- Снятие лайков со всех выбранных треков одним действием, с отображением прогресса и подтверждением изменений сервисом.
- Компактные кнопки загрузок и счётчик выделенных треков.
- Нижняя строка компактно показывает версию, RAM и CPU; сохранение замеров перенесено в настройки.
- Пометка «Офлайн» отображается рядом с качеством звука в проигрывателе.
- Настройка трея применяется при закрытии крестиком. Обычное сворачивание оставляет приложение на панели задач.
- Папки музыки, настроек и кэша называются Yamuse. Прежние данные переносятся без повторного скачивания.
- Также доступны сортировка списков, нормализация громкости в настройках, управление загрузками и полное удаление приложения с его данными.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
