# Yamuse 0.3.8

Изменения относительно опубликованной [версии 0.3.7](https://github.com/senduora/yamuse/releases/tag/v0.3.7).

- Новое название Yamuse и собственный логотип в боковой панели, окнах, трее и установщике.
- Новый мини-плеер с обложкой, названием и исполнителем, шкалой воспроизведения, лайком, громкостью и переключением треков.
- Закрепление мини-плеера поверх окон и быстрый переход к основному окну.
- Тёмные заголовки настроек и диалогов в стиле приложения.
- Обновлённая документация, сведения об источниках и лицензия MIT.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
