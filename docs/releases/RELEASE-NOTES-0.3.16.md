# Yamuse 0.3.16

Изменения относительно опубликованной [версии 0.3.14](https://github.com/senduora/yamuse/releases/tag/v0.3.14).

- Акцент по преобладающему цвету всей обложки с учётом близких оттенков и плавным переходом за 5 секунд. Автоматический выбор можно отключить, выбрать цвет из палитры или задать HEX-код.
- Мягкий анимированный фон с цветными пятнами в «Моей волне», волне по коллекции и развёрнутом проигрывателе.
- «Волна по этому треку» в контекстном меню списков и проигрывателя — рекомендации Яндекса на основе выбранной композиции.
- Отображение автора плейлиста в карточках и шапке.
- Быстрое открытие больших коллекций с фоновой проверкой скачанных треков.
- Общий прогресс скачивания в плейлисте и разделе «Загрузки», с отдельными счётчиками результатов и компактной индикацией.
- Ускоренная очистка скачанной музыки с прогрессом и отдельная кнопка очистки кэша в настройках.
- Обновлённая кнопка повтора, ровные отступы кнопок и аккуратные состояния фокуса. Нажатие названий, альбомов и исполнителей ограничено областью текста; подсветка плавно снимается при уходе курсора.
- Профиль и нижние действия размещены внизу боковой панели, проигрыватель выровнен по основному содержимому.
- Плавный ход таймлайна и согласованное управление перемоткой и громкостью в обычном, развёрнутом и мини-плеере.
- Плавная прокрутка до начала и конца списков.
- Предложение обновить установленное приложение при запуске: скачивание и перезапуск одной кнопкой.
- История версий перенесена в docs/releases/.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
