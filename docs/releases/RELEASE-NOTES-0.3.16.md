# Yamuse 0.3.16

- Цвет по обложке учитывает близкие оттенки по всей площади изображения. Все элементы проигрывателя плавно меняют акцент за 5 секунд.
- Более выразительные мягкие цветовые пятна в фоне волны и развёрнутого проигрывателя.
- Профиль и нижние действия размещены внизу боковой панели, проигрыватель выровнен по основному содержимому.
- Тонкая индикация скачивания плейлиста с короткими понятными подписями.
- Плавный ход таймлайна и согласованное управление перемоткой и громкостью в обычном, развёрнутом и мини-плеере.
- Плавная прокрутка до начала и конца списков.
- Проверка обновлений при запуске с предложением обновить приложение и перезапустить его одной кнопкой.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
