# Yamuse 0.5.3

Изменения относительно опубликованной [версии 0.5.2](https://github.com/senduora/yamuse/releases/tag/v0.5.2).

- Подсветка треков при наведении и кнопка Play на обложке теперь плавно появляются и исчезают.
- Подсветка пунктов меню действий трека стала плавной, в том числе при навигации с клавиатуры.
- Исправлена раскладка списков: значки лайка и скачивания находятся слева от обложки. В избранном убраны порядковые номера; в плейлистах и альбомах они сохранены.
- Имена исполнителей под названием альбома стали ссылками на их страницы. Если исполнителей несколько, можно выбрать каждого отдельно.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**. Оба пакета включают .NET 10 runtime.
