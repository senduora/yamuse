# Yamuse 0.5.1

Изменения относительно опубликованной [версии 0.5.0](https://github.com/senduora/yamuse/releases/tag/v0.5.0).

- Избранное сохраняется в отдельном кэше для каждого аккаунта после первой полной загрузки. При следующем входе список показывается из кэша, пока приложение проверяет изменения на сервере.
- При обычном обновлении коллекции метаданные загружаются только для новых треков. Сохранённые сведения периодически обновляются; кнопка обновления позволяет перечитать их сразу. Текущий список остаётся доступным во время запроса.
- Подгрузка избранного больше не выполняет проверку скачанных файлов в потоке интерфейса. Новые строки добавляются небольшими порциями, а плавная прокрутка сохраняет движение при добавлении треков в конец списка.
- В белой теме цвет обложки значительно заметнее в динамическом фоне, в том числе в большом проигрывателе. Сохранены мягкие переходы, читаемость текста и оформление тёмной темы.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**. Оба пакета включают .NET 10 runtime.
