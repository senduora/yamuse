# Yamuse 0.7.0

В этой версии можно восстановить запуск после прерванного удаления и выбрать, что делать, если при выходе не удалось сохранить данные. Также исправлены воспроизведение, офлайн-загрузки и обновление приложения. Предыдущий стабильный выпуск — [Yamuse 0.6.2](https://github.com/senduora/yamuse/releases/tag/v0.6.2).

## Выход и восстановление

- Если не удалось сохранить очередь, позицию трека или настройки, Yamuse предлагает повторить запись, вернуться в приложение или выйти без последних изменений. После отмены выхода продолжаются только те загрузки, которые выполнялись до него.
- Если полное удаление прервалось до очистки данных, при следующем запуске можно отменить незавершённый запрос и снова открыть Yamuse.

## Воспроизведение и библиотека

- После временного обрыва соединения плеер может повторно запросить недостающую часть трека. Исправлены переходы между короткими треками, пауза при смене аудиоустройства и выбор сохранённой копии для воспроизведения.
- «Моя волна» сохраняет текущую сессию при отмене загрузки новой станции. Удаление играющего офлайн-трека корректно завершает учёт прослушивания.
- В очереди с повторяющимися треками переход «Назад» выделяет именно играющее вхождение. При удалении текущего трека на паузе следующий остаётся на паузе. Исправлены отмена удаления в случайном порядке и выбор строки с клавиатуры.
- «Мне нравится» показывает сохранённый список при открытии и сверяет его с сервером. Изменения с другого устройства учитываются при автоскачивании. Ошибка отдельной загрузки больше не блокирует новые треки, а явно поставленная пауза сохраняется.
- Исправлено восстановление офлайн-библиотеки после прерывания записи или очистки. При недоступной локальной папке «Документы» остаются доступны вход и потоковое воспроизведение.
- Исправлены повторная загрузка обложек и текстов песен, сохранение строки синхронного текста на паузе и отображение сохранённой позиции в мини-плеере.

## Обновления

- Перед применением Yamuse сверяет скачанный пакет с официальным выпуском. Временный сбой сети больше не сбрасывает готовое обновление. При очистке старых пакетов проверяются содержимое и идентификатор файла.
- В установщик и Portable включён .NET Desktop Runtime 10.0.15 с исправлениями безопасности для Windows x64.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки скачайте **Yamuse-win-Portable.zip**.
