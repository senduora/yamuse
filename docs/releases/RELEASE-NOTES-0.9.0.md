# Yamuse 0.9.0

- После входа Yamuse сверяет «Мне нравится» с аккаунтом и автоматически продолжает прерванное автоскачивание. Очереди, сохранённые на паузе, ждут команды «Продолжить».
- Исправлено сохранение запасного MP3 при расхождении заявленного и измеренного битрейта. Yamuse проверяет длительность и целостность файла и показывает измеренный битрейт. Для неудачных загрузок откройте «Центр загрузок» и нажмите «Повторить».

Предыдущий стабильный выпуск — [Yamuse 0.8.1](https://github.com/senduora/yamuse/releases/tag/v0.8.1).

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки скачайте **Yamuse-win-Portable.zip**.
