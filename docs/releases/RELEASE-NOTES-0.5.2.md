# Yamuse 0.5.2

Изменения относительно опубликованной [версии 0.5.1](https://github.com/senduora/yamuse/releases/tag/v0.5.1).

- Исправлена загрузка обложек текущего трека и очереди после перезапуска. Обложки сохраняются вместе с очередью, а недостающие загружаются в фоне. Позиция трека и порядок очереди сохраняются; воспроизведение продолжается по нажатию Play.
- Исправлен выбор обложки для треков, доступных в нескольких альбомах: используется обложка нужного альбома.
- Исправлены добавление треков в плейлисты и чтение обновлённого списка треков.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**. Оба пакета включают .NET 10 runtime.
