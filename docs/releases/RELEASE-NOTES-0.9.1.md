# Yamuse 0.9.1

После перезапуска «Мне нравится» загружается автоматически. Yamuse читает кэш и сверяет список с аккаунтом, пока очередь загрузок восстанавливается в фоне. Ручная пауза автоскачивания сохраняется.

Предыдущий стабильный выпуск — [Yamuse 0.9.0](https://github.com/senduora/yamuse/releases/tag/v0.9.0).

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки скачайте **Yamuse-win-Portable.zip**.
