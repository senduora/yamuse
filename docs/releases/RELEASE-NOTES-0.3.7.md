# Yamuse 0.3.7

Первый опубликованный выпуск.

- Вход через страницу Яндекса, избранное, коллекция и поиск по трекам, исполнителям, альбомам и плейлистам.
- «Моя волна», волна по коллекции, очередь воспроизведения и предзагрузка следующего трека.
- Скачивание треков и плейлистов, настройка числа одновременных загрузок и автоскачивание избранного.
- Обложки и тексты песен с синхронизацией при наличии таймкодов; дополнительные источники текста — LRCLIB и Genius.
- Карточки исполнителей, переход к каждому исполнителю из нижнего плеера и открытие альбома по названию в списке треков.
- Единое оформление кнопок и текстовых ссылок, плавная прокрутка с учётом физических пикселей экрана.
- Установщик для Windows 10/11 x64 со встроенным .NET Runtime и обновлениями через GitHub.
