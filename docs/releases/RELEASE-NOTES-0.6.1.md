# Yamuse 0.6.1

Изменения относительно опубликованной [версии 0.6.0](https://github.com/senduora/yamuse/releases/tag/v0.6.0).

- Исправлено повторное включение автоскачивания после очистки скачанной музыки: избранное загружается без дополнительного нажатия «Скачать целиком». Если список избранного ещё обновляется, загрузка начинается после его получения.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**. Оба пакета включают .NET 10 runtime.
