# Yamuse 0.3.13

- Кнопка «Убрать лайк» и контекстное меню в центре загрузок для удаления трека из «Мне нравится», включая недоступные композиции.
- Обновление избранного сразу после подтверждённого снятия лайка, с отметкой в истории загрузок.
- Исключение убранных треков из повторных загрузок избранного.
- Сохранение обновлённой коллекции при запоздалых ответах её загрузки.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
