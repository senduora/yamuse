# Версии Yamuse

Версия приложения имеет вид `X.Y.Z`:

- `X` увеличивается при крупном обновлении.
- `Y` увеличивается при добавлении небольших возможностей в рамках текущего `X`; `Z` начинается с нуля.
- `Z` увеличивается при исправлениях ошибок и неточностей без нового функционала.

Стабильный выпуск `0.4.0` объединяет новые возможности после опубликованной `0.3.16`. Исправления после него получают номера `0.4.1`, `0.4.2` и далее. Следующий набор небольших возможностей относится к `0.5.0`.

Для локальной подготовки выпуска используется суффикс: `0.4.0-preview.1`, затем `0.4.0-preview.2`. Исправления внутри подготовки увеличивают номер preview. Стабильная `0.4.0` новее любой `0.4.0-preview.N`; `preview.10` новее `preview.2`. Номер локальной сборки сам по себе не означает публикацию или разрешение на установку.

Полная версия хранится в `Version` и `InformationalVersion` проекта и показывается в строке версии и настройках обновлений. Числовые Windows/.NET-метаданные `AssemblyVersion` и `FileVersion` для линии `0.4.0` равны `0.4.0.0`. Preview и стабильный выпуск различаются полной версией. При смене `X.Y.Z` числовые поля меняются согласованно. Идентификатор пакета `YMusic.Native` сохраняется.

Перед стабильной сборкой `Version` и `InformationalVersion` устанавливаются в `0.4.0`. Затем заново выполняются сборка и проверки. Перед упаковкой сверяются полная версия DLL, ожидаемая версия пакета и SHA-256 проверенной DLL: числового `AssemblyVersion` недостаточно.

`Pack-Installer.ps1` принимает стабильную версию `X.Y.Z` и проверяет совпадение с полной версией DLL. При сборке из исходников он также проверяет отсутствие prerelease-суффикса в `Version` проекта. Проверки несоответствия выполняются до создания рабочих папок и получения инструментов. Параметр `ExpectedProductSha256` позволяет привязать пакет к проверенной DLL.

Переносимая версия проверяет опубликованный стабильный GitHub Release и сравнивает полные семантические версии с помощью Velopack. Стабильная `0.4.0` может быть предложена поверх `0.4.0-preview.N`; равная или более старая версия не предлагается. Draft и prerelease не входят в этот источник. Установленный клиент использует семантическую версию пакета Velopack.

Политика применяется к новым версиям. Существующие теги, опубликованные номера и исторические описания выпусков не переименовываются. Каждое описание охватывает все изменения после фактически опубликованного предыдущего стабильного Release; промежуточные локальные сборки отдельной базой не становятся. Порядок проверки базы описан в [руководстве упаковки](../tools/packaging/README.md#описания-опубликованных-выпусков).
