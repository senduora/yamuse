# Yamuse 0.3.12

- Сортировка списков по названию, исполнителю, альбому, длительности и наличию скачанного файла.
- Нажимаемые заголовки колонок и компактный выбор сортировки рядом с названием раздела.
- Сортировка плейлистов, альбомов, исполнителей, результатов поиска и офлайн-коллекции.
- Отдельные критерии для центра загрузок: состояние, прогресс, размер и причина ошибки.
- Запоминание выбранного поля и направления для каждого раздела, возврат к исходному порядку.
- Сохранение выделения, групп поиска и текущего воспроизведения при изменении сортировки.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.
