# Yamuse 0.3.11

- Быстрый запуск онлайн-треков до полной загрузки с поддержкой перемотки и зашифрованных аудиодиапазонов.
- Сохранение очереди, позиции, перемешивания и повтора для вашего аккаунта. Продолжение прослушивания по нажатию Play.
- Новый раздел «Загрузки»: прогресс каждого трека, пауза, продолжение, повтор неудачных загрузок и занимаемое место.
- Настройка выравнивания громкости с локальным кэшем измерений и сохранением исходных аудиофайлов.
- Более отзывчивая прокрутка с точным колесом мыши и плавное продолжение движения обычным колесом.
- Обложки персональных подборок на главной и полное удаление приложения со скачанной музыкой через настройки.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.

В установленной версии обновление доступно в **Настройках**: «Проверить обновления» → «Скачать обновление» → «Обновить и перезапустить».
