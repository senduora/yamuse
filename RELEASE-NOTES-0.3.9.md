# Yamuse 0.3.9

- Настраиваемый кроссфейд от 0 до 10 секунд с предзагрузкой следующего трека.
- Настройки звука, загрузок и приложения теперь открываются в основном окне.
- Обновлённые карточки главной страницы, читаемые подписи и мягкие состояния наведения.
- Сохранение открытых настроек и выбранных значений при обновлении плейлистов.
- Улучшенная отзывчивость при работе с офлайн-коллекцией.

Для установки скачайте **Yamuse-win-Setup.exe**. Для запуска из папки — **Yamuse-win-Portable.zip**.

В установленной версии обновление доступно в **Настройках**: «Проверить обновления» → «Скачать обновление» → «Обновить и перезапустить».
